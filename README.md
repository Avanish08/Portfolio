# Avanish Ojha — AI/ML Developer Portfolio

A responsive React + Vite portfolio focused on AI/ML, Data Science and software development.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build for production

```bash
npm run build
```

The production files are generated in `dist/`.

## Deploy

This project can be deployed to Netlify or Vercel. For Netlify, the build command is `npm run build` and the publish directory is `dist`.
